# Security policy

Please do not report security issues in public issues.

Report vulnerabilities privately through GitHub's **Report a vulnerability** flow on this repository's Security tab. Use that same private route for anything containing credentials, tokens, real hostnames, real IPs, appliance logs, or customer data.

Public issues are for non-sensitive bugs and feature requests only. If you are unsure whether your report is sensitive, use the private reporting flow.

When reporting, include the affected version, a minimal description, and sanitized reproduction details. Never include real credentials, real appliance addresses, logs with customer data, or internal URLs.
